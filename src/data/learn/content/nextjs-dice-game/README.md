# Next.js Dice Game

Practice building an interactive game with the Next.js App Router and TypeScript.

Roll the dice, lock the values you want to keep, and keep rolling until every die shows the same number.

## What You Will Practice

- Creating an App Router page
- Using a Client Component for interactive UI
- Typing component props and state
- Managing state with `useState`
- Responding to user events
- Rendering lists from arrays

## Key Files

- `app/page.tsx` renders the page.
- `components/DiceGame.tsx` contains the game state and logic.
- `components/DiceTile.tsx` renders one typed die button.
- `app/globals.css` controls the look and layout.

## Run Locally

```bash
npm install
npm run dev
```
