# React Dice Game

Practice core React ideas by building a small dice matching game.

Roll the dice, lock the values you want to keep, and keep rolling until every die shows the same number.

## What You Will Practice

- Writing JSX
- Managing state with `useState`
- Responding to button clicks
- Rendering lists with `.map()`
- Passing props to a child component
- Showing different UI after the player wins

## Key Files

- `App.jsx` contains the game state and main UI.
- `DiceTile.jsx` renders one clickable die.
- `styles.css` controls the look and layout.
